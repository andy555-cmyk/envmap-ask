# 현장 질문 답변 — AI 프록시 (Gemini)

## 왜 프록시인가

API 키를 HTML 에 넣을 수 없다(프로젝트 절대 규칙).
키는 이 서버의 **환경변수에만** 있고, 브라우저는 키를 본 적이 없다.

**카드(근거)는 서버에 두지 않는다.** 페이지가 이미 갖고 있는 것을 요청에 실어 보낸다.
사본을 만들면 언젠가 어긋난다 — 이 프로젝트에서 이미 여러 번 겪었다.

## AI 없이도 작동한다

각 지도의 질문창은 **카드 검색만으로 이미 답한다**(비용 0 · 지연 0 · 환각 0).
이 프록시는 그 위에 얹는 보조다. 연결하지 않아도 지도는 정상이다.

## 대표가 해야 하는 것 (3단계)

### 1. 제미나이 키 발급
https://aistudio.google.com/apikey → **Create API key**
무료 한도가 있어 우선 그대로 써 보면 된다.

### 2. 클라우드타입에 서비스 추가
- 콘솔 → 프로젝트 `soetae-analysis` → **+ 새 서비스**
- 저장소 `andy555-cmyk/gijang-map` · 브랜치 `main`
- 종류 **Node.js** · **서브경로(subpath) `chat`**
- 시작 명령 `node server.js` · 포트 `8080`
- **환경변수 2개**
  | 이름 | 값 |
  |---|---|
  | `GEMINI_API_KEY` | 1번에서 받은 키 |
  | `ASK_PASS` | 두 사람이 쓸 접속 암호(아무거나 정한다) |

  선택: `ASK_MODEL`(기본 `gemini-2.0-flash`) · `ASK_MONTH_CAP`(기본 3000회) ·
  `ASK_ORIGIN`(기본 라이브 주소)

- 배포 후 주소를 복사한다. 예) `https://port-0-...sel3.cloudtype.app`
- 확인: 그 주소 뒤에 `/health` 를 붙여 열면 `{"ok":true,...}` 가 떠야 한다

### 3. 지도에서 연결
지도 좌측 질문창 아래 **「AI 연결하기」** → 주소와 암호를 한 번만 입력한다.
그 브라우저에만 저장되고 페이지에는 들어가지 않는다.

## 비용 관리

- `ASK_MONTH_CAP` 을 넘으면 서버가 거부한다(초과 과금이 구조적으로 불가능)
- `/health` 로 이번 달 사용량을 볼 수 있다
- 두 사람만 쓰므로 월 600질문 기준 수천 원 수준

## 답변 규칙 (server.js 의 SYS)

1. 보낸 근거 카드에 있는 내용만으로 답한다. 없는 수치를 만들지 않는다
2. 카드로 답할 수 없으면 **"그 자료는 이 지도에 없습니다"** 라고 분명히 말한다
3. 수치에는 **출처·기준일·공간단위**를 반드시 붙인다
4. 카드의 한계(합산 금지 등)를 반드시 함께 전달한다
5. 공간단위가 다른 수치를 한 문장에서 비교하지 않는다
6. 현장에서 그대로 읽을 수 있게 3~5문장

`temperature 0.1` 로 고정해 표현 흔들림을 줄였다.
